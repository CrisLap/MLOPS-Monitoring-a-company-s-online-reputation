MLOps Project

🚀 Online Reputation API

Monitoring and sentiment analysis system for tracking company reputation across social media, built on a production-grade MLOps pipeline.

End-to-end system using FastText, MLflow, FastAPI, Docker, and Hugging Face for deployment and model versioning — with continuous training, drift detection, and CI/CD automation.

Architecture

How the pipeline works

TrainingFastText, hyperparameters via autotune.
EvaluationMetrics and runs tracked in MLflow.
GateDeploy only if F1 clears the threshold.
DeployVersioned model artifacts on Hugging Face.
MonitorDrift on tweet length and class balance.

Key features

What it does

CLASSIFYSentiment classification: positive / neutral / negative.
DETECTData drift detection on tweet length and class distribution.
RETRAINAutomated retraining pipeline triggered on drift.
GATEF1-score gated deployment, threshold ≥ 0.60.
SHIPDockerized API and training pipeline.

🚀 Online Reputation API

Monitoring and sentiment analysis system for tracking company reputation across social media using a production-grade MLOps pipeline.

🧠 Project Summary

This project implements an end-to-end MLOps system using FastText, MLflow, FastAPI, Docker, and Hugging Face for deployment and model versioning.

The goal is to automatically analyze social media sentiment and monitor online reputation with continuous training, drift detection, and CI/CD automation.

🏗️ Architecture Overview

  • Training pipeline: FastText + autotune + MLflow tracking
  • Serving layer: FastAPI with /predict, /health, /metrics
  • Model versioning: Hugging Face Model Hub (.ftz artifacts)
  • CI/CD: GitHub Actions (train → test → deploy)
  • Monitoring: Prometheus + Grafana dashboards

📊 Key Features

  • Sentiment classification (positive / neutral / negative)
  • Data drift detection (tweet length + class distribution)
  • Automated retraining pipeline
  • F1-score gated deployment (threshold ≥ 0.60)
  • Dockerized API + training pipeline
